##### 1 [alice/tools/diagnostics.py]
These imports are unused (`datetime`, `Path`, and `Any`). The repository's Ruff configuration enables F401, so this new module makes the CI lint job fail before tests run.

##### 2 [alice/tools/diagnostics.py]
Gerçek `Config` sınıfında `brain` alanı yok; model zinciri `roles` property'sinden geliyor (`alice/config.py:998-1010`). Bu satır `app_state` varsayılan `all`/`config` çağrısında `AttributeError` üretir; mevcut testte `MagicMock` kullanıldığı için hata görünmüyor. `cfg.roles.get("brain")` üzerinden okuyun.

##### 3 [alice/tools/diagnostics.py]
`out_lines` and `err_lines` are assigned but never read. Ruff enables F841 in CI, so these unused locals make the diagnostics module fail lint; remove them (or use them in the output processing).

##### 4 [alice/tools/files.py]
`mark_read(ctx, p)` runs before `_find_symbol_range`; when the requested symbol is missing, `read_file` raises but still records the file as successfully read. The agent can then call `edit_file` without ever receiving the file contents, bypassing the existing read-before-edit safety check. Mark the file only after symbol resolution and successful rendering.

##### 5 [alice/tools/github.py]
`remotes_out` is inserted verbatim into the report before the credential check. If a remote is `https://user:token@github.com/...`, `audit` exposes the full token to the agent/logs; appending a warning afterward does not redact it. Display a redacted copy while retaining the raw value only for detection.

##### 6 [alice/tools/shell.py]
Creating the dump with `Path.write_bytes` uses ordinary file permissions (typically 0644 on POSIX), so complete command output—including secrets that were not present in the truncated response—can become readable by other users in the temp directory. Create it with a private temporary-file API such as `NamedTemporaryFile`/`mkstemp` instead.

##### 7 [tests/test_diagnostics.py]
The diagnostics test also invokes the Windows-only `py -3` launcher. On the Ubuntu jobs this returns a nonzero status, so the test asserts success on a failed command. Use `python`/`sys.executable` instead.

##### 8 [tests/test_shell_output.py]
The CI test matrix includes Ubuntu, where `py` is not the Python launcher. This command therefore exits 127 under the bash path in `RunCommand`, so the new test fails before it can verify truncation. Use a portable interpreter invocation (for example `python` or `sys.executable`) in the test.

##### 9 [alice/core/cli.py]
`WinHotkeys` is a Windows-only RegisterHotKey implementation, but this path is enabled by the non-empty default `game_mute_key` on every platform. On Linux/macOS its worker raises because `ctypes.windll` is unavailable, `_ready` is never set, and `start()` blocks for five seconds before falsely succeeding. Guard registration with the platform check, as the other `WinHotkeys` callers do.

##### 10 [alice/tools/diagnostics.py]
When `core_store` is absent this creates a new SQLite `Store`, but the local instance is never closed. Repeated diagnostics calls can leave database connections/file handles open; use a context manager for a local store or retain it in `ctx.state` so normal cleanup closes it.

##### 11 [alice/tools/diagnostics.py]
`Store.events` only accepts `since`, `kind`, and `limit`; it has no `severity` keyword. Every normal `service_diagnose` call therefore raises `TypeError` here, which the surrounding `except` turns into “Store okunurken hata oluştu”, so stored warnings/errors are never reported. Fetch with the supported signature and filter `e.severity` in Python.

##### 12 [alice/tools/diagnostics.py]
The failure parser only matches a nonstandard `_+ FAIL:`/`_+ ERROR:` block. Normal pytest output uses lines such as `FAILED tests/test_x.py::test_y - ...` and a `1 failed in ...` summary, so `failures` stays empty and the tool falls back to dumping the entire unfiltered output instead of reporting the broken assertion as promised. Parse pytest's actual failure/summary format and cover a failing test case.

##### 13 [alice/tools/files.py]
`rg` bulunmayan makinelerde artık `SEARCH_MAX_FILES` verildiği için `max_results=1` gibi küçük bir sayfada bile arama 20.000 dosyaya kadar tüm eşleşmeleri bellekte topluyor. Bu, önceki `offset + max_results` sınırını kaldırarak büyük çalışma klasörlerinde her grep çağrısını gereksiz biçimde yavaşlatabilir; toplamı hesaplamayı sonuç toplama sınırından ayırın ya da taramayı kontrollü tutun.

##### 14 [alice/tools/files.py]
When `offset` is past the last page, `page` is empty but `total` is nonzero, so this branch reports `eşleşme yok` and omits the existing total. That is misleading for pagination: there are matches, just none on this page.

##### 15 [alice/tools/files.py]
Buradaki `toplam` sayısı `rg` yolunda güvenilir değil: `_rg` content modunda `-m 100` ile dosya başına 100 eşleşmede kesiliyor. Tek dosyada 100'den fazla eşleşme varsa sayfalama kalanlarını hiç göremez ve bu mesaj eksik toplamı gerçek toplam gibi raporlar. Ya bu sınırı pagination/count için kaldırın ya da toplam iddiasını yalnızca tam tarama yapıldığında gösterin.

##### 16 [alice/tools/github.py]
`_token_candidates` MCP sunucusu ayarlarından da token döndürebiliyor, ancak audit'in kaynak tespiti yalnızca gh, `TOKEN_ENVS` ve `GITHUB_MODELS_TOKEN`'ı kontrol ediyor. Seçilen token MCP config'den geldiyse rapor `Auth: bilinmiyor` olur; bu da eklenen "aktif auth kaynağı" raporunun amacını bozar. MCP adaylarını da aynı kaynak çözümlemesine dahil edin.

##### 17 [alice/tools/github.py]
The module documentation above still says the lookup order is environment/MCP/Models and `gh auth token` last, but this change makes the `gh` token the first candidate. That stale contract can lead maintainers to undo the intended precedence; update the documentation (and the related `github_token` docstring) to match the new order.

##### 18 [alice/tools/github.py]
This audit only prints configured remote URLs; it never runs a bounded fetch/`ls-remote` check or records reachability. Consequently a broken or unreachable remote can still end with “Sorun bulunmadı”, despite the PR's audit contract promising fetch health. Add an explicit connectivity check or remove that claim from the audit behavior.
